2D CREATION — PERFORMANCE-OPTIMIZED WEBSITE

OPENING THE WEBSITE
1. Right-click the downloaded ZIP and select "Extract All".
2. Open the newly extracted folder.
3. Double-click OPEN-THIS-FIRST.html or index.html.
4. Close any old Chrome tab showing ERR_FILE_NOT_FOUND. That tab points to an
   older local file location and cannot repair itself.

IMAGE VERIFICATION
- All 17 homepage images remain included: 7 certification logos and 10 garment
  photographs.
- The original image files, pixels, dimensions, and image presentation are
  unchanged. No image was cropped, removed, altered, or recompressed.
- The homepage now loads the images from assets/images/embedded instead of
